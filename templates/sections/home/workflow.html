Try the complete story first

No clone. No API keys.

A deterministic demo goes from healthy trace to blocked regression.

$ uv tool install "maida-ai==0.6.1"
$ maida demo --regression
Open quickstart ->

Choose the behavior you want to protect.

A short policy example from the pinned release docs:

version: 2
trials: 3
fail_fast: true
metrics:
  stop_condition_reached: {kind: invariant, require: true}
  step_count:
    kind: measured
    direction: upper
    tolerance: {relative: 0.5}

  --policy .maida/policy.yaml --format markdown
