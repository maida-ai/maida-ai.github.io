06 How it works

From one agent run
to a merge gate.

  1. 01
    Capture one task

    Use your coding agent in your repository.

  2. 02
    Review a few checks

    Choose the observed behavior you want to protect.

  3. 03
    Try a change

    See a pass, a deliberate failure, and repair.

  4. 04
    Add CI when ready

    Verify the repository boundary on a real PR.

For your own repository, install with uv tool install "maida-ai==0.6.1", then follow Check a Claude Code task for capture setup, your first report, and review of the next change.
